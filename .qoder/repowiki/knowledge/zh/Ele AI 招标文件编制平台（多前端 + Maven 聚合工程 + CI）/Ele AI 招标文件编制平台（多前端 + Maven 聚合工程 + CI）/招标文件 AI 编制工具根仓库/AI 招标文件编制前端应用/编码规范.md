- API 调用按业务域拆分到 `src/api/*.ts`，统一通过 `@/utils/request` 导出的 axios 实例发起，禁止直接 import axios。
- 路由采用 `component: () => import(...)` 懒加载模式，并在 `meta.title` 中声明页面标题供 `beforeEach` 设置 `document.title`。
- Pinia store 按领域拆分为独立文件（project.ts / requirement.ts / user.ts / theme.ts），仅 `store/index.ts` 暴露 createPinia 实例。
- 全局样式以 SCSS 变量/覆盖文件（_tokens.scss、_spacing.scss、_typography.scss、_element-overrides.scss）+ base 重置 + index.scss 聚合的方式组织。
- Axios 响应拦截器约定后端统一返回 `{ code, message, data }`，code=200 时解包 data，code=401 触发 401 弹窗并调用 userStore.logout()。
