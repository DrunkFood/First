标准 Vue3 SPA 分层结构：入口 `src/main.ts` 挂载 Pinia、ElementPlus（中文 locale）、Vue Router 与根组件；路由在 `src/router/index.ts` 集中声明，通过 `meta.requiresAuth/guest` 配合 `beforeEach` 实现登录态守卫，并按功能域拆分为 requirement/project/policy/message 等子目录。

- 状态层：`src/store/` 使用 Pinia 按领域拆分（project / requirement / user / theme），由 `store/index.ts` 统一导出实例。
- API 层：`src/api/` 每个业务模块一个文件，全部通过 `src/utils/request.ts` 封装的 axios 实例调用，该实例统一注入 Bearer token、拦截 401 弹窗并自动登出、透传 blob 响应。
- 视图层：`src/views/` 按业务域组织页面，复杂页面（如 ProjectDetail）内嵌 `phases/` 分阶段子组件；通用 UI 下沉到 `src/components/{ai,detection,document,editor,message,preview,project,requirement,review}/`。
- 构建与代理：`vite.config.ts` 配置多后端开发代理（/core-api → 8082、/ai-api → 8083、/file-api → 8081、/support-api → 8080），生产 base 为 `/ele-ai-tender-web/`，并通过 Rollup `manualChunks` 将 element-plus 与 vue-vendor 单独分包输出到 `ele-ai-tender-web/dist/assets`。
- 样式体系：`src/styles/` 下 `_tokens.scss`、`_spacing.scss`、`_typography.scss`、`_element-overrides.scss` 作为变量层，`base/_reset.scss`、`_global.scss` 作为基础样式，最终由 `index.scss` 聚合引入。
