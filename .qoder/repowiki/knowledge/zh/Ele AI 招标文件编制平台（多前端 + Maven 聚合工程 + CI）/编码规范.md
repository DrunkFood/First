- 后端模块遵循 controller/service/mapper/entity/dto 分层结构，异常通过 GlobalExceptionHandler 统一处理
- 前后端通过 REST API 交互，前端 API 封装在 src/api/*.ts 中，类型定义在 src/types/*.ts 中
- 配置按环境分离（application-dev.yml / application-test.yml / application-wuyx.yml），日志通过 logback-spring.xml 统一配置
- 跨模块通信通过 ele-ai-tender-interaction 定义的 SPI 契约与 DTO 枚举进行，禁止直接依赖其他业务模块
