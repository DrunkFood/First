根目录作为聚合入口，将业务域拆分为七个独立可部署的 Spring Boot 子模块：core（项目/阶段/评审主流程）、ai（大模型调用与任务调度）、file（Markdown/Word 文档引擎）、support（系统支撑：用户/角色/模板/短信等），并通过 ele-ai-tender-common 共享实体、枚举、DTO 以及 ele-ai-tender-common-interaction 定义的 Interaction SPI（AiTaskCreateRequest/Callback、签名校验、结果提取）实现跨服务异步协作；两个 Vue3+Vite 前端分别面向业务编制与系统管理，均通过各自 .env 指向同一套后端 REST API。

运行形态由顶层 Jenkinsfile-* 流水线驱动：Jenkinsfile-core.groovy / Jenkinsfile-ai.groovy / Jenkinsfile-file.groovy / Jenkinsfile-support.groovy 分别打包对应 jar，Jenkinsfile-core-web.groovy / Jenkinsfile-support-web.groovy 构建 dist 静态资源，最终组合出「独立部署」「嵌入第三方系统」「一体机」三种交付产物。

docs/rules 下的 CODE_CONVENTIONS.md、AI_MODULE_SPEC.md、CORE_MODULE_SPEC.md 等规范文件是所有 Java 子模块共同遵守的契约，docs/plans 与 docs/context 则按日期前缀组织需求上下文，贯穿前后端联调。
