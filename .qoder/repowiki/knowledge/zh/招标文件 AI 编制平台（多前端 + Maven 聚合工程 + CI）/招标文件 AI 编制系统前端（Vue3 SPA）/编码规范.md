- API 模块按领域拆分到 `src/api/*.ts`，每个文件仅暴露该领域的 axios 方法，不直接耦合业务逻辑。
- 所有 HTTP 请求统一走 `src/utils/request.ts` 导出的 `request.get/post/put/delete`，禁止在组件中直接使用 axios。
- 路由定义集中在 `src/router/index.ts`，使用 `component: () => import('@/views/...')` 懒加载，并在 meta 中声明 title 与 icon。
- Pinia store 使用 Composition API 风格 `defineStore('id', () => { ... })`，状态以 ref 声明、计算属性以 computed 暴露。
- 环境变量通过 `vite.config.ts` 的 `loadEnv(mode)` 读取，并以 `VITE_` 前缀命名，区分 support-api 与 file-api 两个后端地址。
