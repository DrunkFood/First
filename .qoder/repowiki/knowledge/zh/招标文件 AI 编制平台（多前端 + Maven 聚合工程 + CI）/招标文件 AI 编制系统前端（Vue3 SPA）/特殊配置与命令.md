支持多环境模式：`npm run dev`（默认 development）、`npm run dev:local`（localdev 模式）、`npm run dev:test`（test 模式），通过 `.env.development` / `.env.localdev` / `.env.test` 中的 `VITE_SUPPORT_API_URL` 与 `VITE_FILE_API_URL` 指定后端代理目标；生产构建 `npm run build` 输出到 `ele-ai-tender-support-web/`，需部署到 Nginx 且 base 路径为 `/ele-ai-tender-support-web/`。
