顶层 `pom.xml` 以 JDK 21 / Spring Boot 3.2.2 为统一基线，通过 `<dependencyManagement>` 集中管理内部模块与第三方依赖版本；各业务子模块仅声明自身依赖，不重复引入版本。

- 分层结构：每个可运行模块均遵循 `controller → service(接口+impl) → mapper(MyBatis Plus)` 三层，并配套 `config/`、`handler/GlobalExceptionHandler`、`dto/request|response`、`resources/application-{dev,test,wuyx}.yml`。
- 公共层 `ele-ai-tender-common`：提供跨模块共享的实体(`entity`)、枚举(`enums`)、DTO、异常、工具类、JWT 鉴权过滤器、数据权限拦截器、访问日志自动装配等，并通过 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 暴露 `InternalFileServiceClientAutoConfiguration`。
- 核心业务 `ele-ai-tender-core`：项目/模板/需求/评审项/检测等业务主域，内置 `statemachine/ProjectStateMachine` 用静态 Map 定义合法状态迁移，`scheduler/AiTaskResultSyncScheduler` 定时拉取异步任务结果。
- AI 服务 `ele-ai-tender-ai`：独立进程，封装 LLM 调用、Prompt 模板、检测引擎(`processor/checker`)、文档生成(`processor/generator`)、动态线程池(`threadpool`)，启动时排除 ZhiPuAi 自动配置以避免未启用模型报错。
- 文件服务 `ele-ai-tender-file`：Word/Markdown 解析与模板渲染(`engine/WordTemplateEngine`、`WordDocumentFixEngine`、`MarkdownToDocumentConverter`)，对外提供文件上传下载及 Word 文档处理 API。
- 支撑中心 `ele-ai-tender-support`：用户/角色/菜单/权限、短信网关、模型路由规则、知识库配置、操作审计等后台管理能力。
- 交互适配层 `ele-ai-tender-interaction`：为兼容 JDK8 的外部系统单独维护一套 Spring Boot 2.7.18 的 starter，包含 `common-interaction`(JDK8 兼容 DTO/SPI)、`interaction-core`(HTTP 客户端与签名)、`interaction-autoconfigure`(控制器与自动装配)、`interaction-spring-boot-starter`(聚合)。该子模块通过覆盖父 BOM 的 spring-boot-dependencies 实现双 JDK 版本共存。

依赖方向：`core` / `ai` / `file` / `support` 均依赖 `common`；`ai` 额外依赖 `common-interaction` 和 `interaction-core`；`interaction-autoconfigure` 依赖 `interaction-core` 与 `common-interaction`；`interaction-spring-boot-starter` 聚合前两者。四个 Spring Boot 应用各自独立打包部署。
