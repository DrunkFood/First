顶层仓库按「前端—后端—文档—CI」四层组织：
- 前端层：`ele-ai-tender-support-frontend`(5174) 管理支撑中心，`ele-ai-tender-frontend`(5173) 面向业务编制，均通过 Vite devServer 将 `/support-api/*`、`/file-api/*`、`/core-api/*`、`/ai-api/*` 代理到对应后端服务。
- 后端层：`ele-ai-tender-system/` 为 Maven 父 POM，按领域拆分为 common / common-interaction / interaction(Starter) / support(8080) / file(8081) / core(8082) / ai(8083) 七个子模块；common 与 common-interaction 作为公共依赖被其余模块引用，interaction Starter 对外暴露 JDK8 兼容的 SPI 供第三方系统接入。
- 跨模块调用：core↔ai 通过 `ai_task` 表异步解耦（core 写入任务 → AiTaskProcessor 轮询执行 → core 读取结果），无直接 HTTP 耦合；core→support 做认证/权限校验，core/ai→file 走文件上传下载接口。
- 基础设施：所有服务共享 MySQL(db=6)、Redis(db=6)、Milvus，统一通过 `X-Trace-Id` 链路追踪，支持环境变量与 `${user.home}/.ele-ai-tender/{module}-local.yml` 覆盖配置。
- CI 层：根目录 6 个 `Jenkinsfile-*.groovy` 分别对应 ai/core-web/core/file/support-web/support 六个构建目标，由统一的 `Jenkinsfile-ai.groovy` 编排触发。
