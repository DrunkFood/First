顶层 `ele-ai-tender-system/pom.xml` 作为父 POM 声明 JDK 21 / Spring Boot 3.2.2 基线并通过 `<dependencyManagement>` 集中锁定内部模块与第三方依赖版本；各业务子模块仅声明自身依赖而不重复引入版本。

依赖方向严格单向：`core` / `ai` / `file` / `support` 均依赖 `common`；`ai` 额外依赖 `common-interaction` 与 `interaction-core`；`interaction-autoconfigure` 依赖 `interaction-core` + `common-interaction`；`interaction-spring-boot-starter` 聚合前两者。四个 Spring Boot 应用（core/ai/file/support）各自独立打包部署，互不依赖。

公共能力通过自动装配注入：`common` 模块在 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 暴露 `InternalFileServiceClientAutoConfiguration`，被其他模块自动装配；`interaction-autoconfigure` 同样通过 `spring.factories` + `AutoConfiguration.imports` 双入口注册。

交互适配层 `ele-ai-tender-interaction` 覆盖父 BOM 的 `spring-boot-dependencies` 将自身编译目标切换为 JDK 8，实现与主工程 JDK 21 并行构建，从而兼容外部调用方。

每个可运行模块遵循统一分层：`controller → service(接口+impl) → mapper(MyBatis Plus)`，配套 `config/`、`handler/GlobalExceptionHandler`、`dto/request|response`、`resources/application-{dev,test,wuyx}.yml`，并由各自的 `*Application.java` 启动。
