第一章 招标公告
一、招标条件
本招标项目某市政道路改造工程已由某市发展和改革委员会以某发改投资〔2024〕XX号批准建设，项目业主为某市住房和城乡建设局，建设资金来自财政资金，项目出资比例为100%，招标人为某市住房和城乡建设局。项目已具备招标条件，现对该项目的施工进行公开招标。
二、项目概况与招标范围
1. 项目名称：某市政道路改造工程
2. 建设地点：某市城区
3. 建设规模：道路全长约5公里，宽度24米，双向六车道
4. 计划工期：240日历天
5. 招标范围：施工图范围内的道路工程、排水工程、绿化工程等
6. 工程质量要求：合格
三、投标人资格要求
1. 本次招标要求投标人须具备市政公用工程施工总承包二级及以上资质，并在人员、设备、资金等方面具有相应的施工能力。
2. 投标人拟派项目经理须具备市政公用工程专业二级注册建造师执业资格，具备有效的安全生产考核合格证书，且未担任其他在施建设工程项目的项目经理。
3. 本次招标不接受联合体投标。
四、招标文件的获取
1. 招标文件获取时间：2024年1月15日至2024年1月22日（法定公休日、法定节假日除外）。
2. 招标文件获取方式：登录某市公共资源交易中心网站下载。
五、投标文件的递交
1. 投标文件递交的截止时间（投标截止时间，下同）为2024年2月5日9时00分。
2. 递交地点：某市公共资源交易中心开标室。
3. 逾期送达的或者未送达指定地点的投标文件，招标人不予受理。
第二章 投标人须知
一、总则
1.1 本次招标的项目名称为某市政道路改造工程，招标人为某市住房和城乡建设局。
1.2 本项目资金来源为财政资金，出资比例100%。
1.3 本项目采用公开招标方式，资格检测方式为资格后审。
二、招标范围及工期
2.1 招标范围：施工图范围内的道路工程、排水工程、绿化工程等。
2.2 计划工期：240日历天。
三、投标人资格要求
3.1 投标人须具备市政公用工程施工总承包二级及以上资质。
3.2 投标人拟派项目经理须具备市政公用工程专业二级注册建造师执业资格。
3.3 投标人须具备有效的安全生产许可证。
四、投标费用
投标人应承担其参加投标所发生的一切费用，不论投标结果如何，招标人均不承担。
第三章 交易需求
一、工程概况
本项目为某市政道路改造工程，位于某市城区，道路全长约5公里。主要建设内容包括道路拓宽改造、排水系统升级、绿化带建设等。
二、技术要求
1. 道路宽度：24米，双向六车道
2. 路面结构：沥青混凝土路面
3. 排水系统：雨污分流，管径DN300-DN1500
4. 绿化带：两侧各3米宽绿化带
三、质量标准
工程质量应符合国家现行工程施工质量验收规范标准，达到合格标准。
四、安全文明施工要求
投标人应制定详细的安全文明施工方案，确保施工安全，减少对周边环境和居民的影响。
第四章 评审办法
一、评审方法
本项目采用综合评分法进行评审，总分100分。
二、评分标准
评审项目 分值 评审内容
资信评审 30分 企业资质、业绩、信誉等
技术评审 40分 施工方案、技术措施、质量保证措施等
商务评审 30分 投标报价
三、中标条件
综合得分最高者为中标候选人。
第五章 合同主要条款
一、合同价款
合同价款采用固定单价合同方式确定。
二、付款方式
1. 预付款：合同价的10%
2. 进度款：按月支付已完成工程量的70%
3. 竣工结算：工程竣工验收合格后支付至结算价的95%
4. 质保金：结算价的5%，质保期满后无息返还
三、工期要求
计划工期240日历天，实际开工日期以开工令为准。
四、质量要求
工程质量应符合国家现行工程施工质量验收规范标准，达到合格标准。
五、保修责任
工程保修期为2年，自工程竣工验收合格之日起计算。
