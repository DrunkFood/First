第一章 招标公告

1.1 招标条件

本招标项目某市政道路改造工程已由某市发展和改革委员会以某发改投资〔2024〕15号文批准建设，项目业主为某市城市建设投资集团有限公司，建设资金来自财政拨款，项目出资比例为100%，招标人为某市城市建设投资集团有限公司。项目已具备招标条件，现对该项目的施工进行公开招标。

1.2 项目概况

项目名称：某市政道路改造工程

建设地点：某市主城区

建设规模：道路全长约5.2公里，红线宽度40米

计划工期：365日历天

招标范围：施工图纸及工程量清单所示全部内容

工程质量要求：达到国家施工验收规范合格标准

第二章 投标人须知

2.1 总则

投标人必须是在中华人民共和国境内注册的独立法人，具备有效的营业执照，并在人员、设备、资金等方面具有相应的施工能力。

投标人须具备建设行政主管部门颁发的市政公用工程施工总承包二级及以上资质，并具备有效的安全生产许可证。

投标人拟派项目经理须具备市政公用工程专业一级注册建造师执业资格，具备有效的安全生产考核合格证书（B证），且未担任其他在施建设工程项目的项目经理。

第三章 技术规格及要求

3.1 工程范围

本项目工程范围包括但不限于以下内容：

  • 道路工程：路基、路面、人行道、绿化带等
  • 排水工程：雨水管道、污水管道、检查井等
  • 照明工程：路灯、配电箱、电缆等
  • 交通工程：标志标线、信号灯、监控设施等

3.2 技术要求

3.2.1 道路工程

路面结构：上面层采用4cm厚AC-13C细粒式沥青混凝土，中面层采用6cm厚AC-20C中粒式沥青混凝土，下面层采用8cm厚AC-25C粗粒式沥青混凝土，基层采用20cm厚水泥稳定碎石，底基层采用20cm厚级配碎石。

路基压实度：填方路段不小于96%，挖方路段不小于95%。

第四章 评标办法

4.1 评标方法

本项目采用综合评估法进行评标。评标委员会按照招标文件规定的评标标准和方法，对投标文件进行评审和比较。评标委员会按照评分高低推荐不超过3名有排序的合格的中标候选人。

评标委员会完成评标后，应当向招标人提交书面评标报告，并推荐合格的中标候选人。招标人根据评标委员会提出的书面评标报告和推荐的中标候选人确定中标人。
