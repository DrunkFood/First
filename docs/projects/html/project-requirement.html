第三章 招标/采购需求

3.1 工程范围

本项目工程范围包括但不限于以下内容：

  • 主体结构工程施工
  • 装饰装修工程施工
  • 给排水及消防系统安装
  • 电气工程安装
  • 通风空调系统安装

3.2 技术要求

3.2.1 主体结构工程

主体结构工程应符合以下技术要求：

  1. 混凝土强度等级不低于C30
  2. 钢筋采用HRB400级钢筋
  3. 结构安全等级为二级
  4. 抗震设防烈度为7度

3.2.2 装饰装修工程

装饰装修工程应符合以下技术要求：

  • 外墙采用真石漆涂料
  • 内墙采用乳胶漆
  • 地面采用防滑地砖
  • 门窗采用断桥铝合金型材
