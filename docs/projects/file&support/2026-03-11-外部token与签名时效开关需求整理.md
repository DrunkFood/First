# 2026-03-11 外部 token 与签名时效开关需求整理

## 背景
- 联调阶段需要放宽外部 token 时效，减少频繁重新跳转。
- 上线前希望通过配置快速收紧时效，避免再次改代码。
- 同时希望签名校验时间窗也可配置，便于与各环境时钟偏差和网关链路耗时匹配。

## 本次需求
- 增加“配置开关”以控制外部 token 有效期。
- 该开关同时支持控制签名有效时间。
- 当前默认外部 token 时效保持 1 周，签名时效默认保持 5 分钟。

## 目标
- `jwt.external-expiration` 生效于：
  - 外部 token JWT 过期时间
  - Redis 外部 token TTL
  - 下发接口返回 `expireIn`
- `signature.expire-seconds` 生效于外部签名校验。
- 两项均可通过不同环境配置覆盖，避免上线前改代码。
