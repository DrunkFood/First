# 2026-03-25 JWT 配置规范文档更新需求整理

- 用户要求将 JWT 配置一致性要求固化到仓库规范文档。

- 在 `AGENTS.md` 中新增 JWT 配置一致性硬性约束。
- 在项目 spec 文档中同步新增对应条款，保证团队执行与文档一致。

## 影响文档
- `AGENTS.md`
- `docs/projects/PROJECT_SPEC_FINAL.md`
- `docs/projects/TENDER_DOCUMENT_PROJECT_SPEC.md`

## 验收标准
