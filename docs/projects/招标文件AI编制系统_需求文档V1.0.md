# 招标文件AI编制系统 - 需求文档

## 1. 系统概述

### 系统名称

招标文件AI编制系统

### 目标用户

- 招标专员：负责业务需求、招标文件的编制工作，并管理政策文件
- 系统管理员：负责系统配置和维护

### 核心价值

通过AI技术辅助生成合规、标准的业务需求、招标文件，提升编制效率和审查质量。

## 2. 功能模块清单

说明：本需求包含以下模块，不包括原型里的统计分析、消息中心、系统设置。且在正式开发时修改模块名称如下

编制业务需求→业务需求管理、项目管理→招标文件管理、模板管理→文件模板管理

| 模块名称   | 功能说明                    | 用户权限 | 管理员权限 |
| ------ | ----------------------- | ---- | ----- |
| 登录模块   | 手机号验证码登录                | 是    | 是     |
| 编制业务需求 | 创建、编辑业务需求，AI辅助生成，智能检测   | 是    | 否     |
| 项目管理   | 项目列表管理，支持直接新建和第三方系统跳转创建 | 是    | 否     |
| 政策文件管理 | 政策文件的上传、分类、查看、删除        | 是    | 是     |
| 模板管理   | 招标文件模板的创建、编辑、预览、状态管理    | 否    | 是     |

### 权限说明

| 角色  | 权限范围             |
| --- | ---------------- |
| 用户  | 登录系统、编制业务需求、管理项目 |
| 管理员 | 平台模板管理、政策文件管理    |

## 3. 详细功能说明

### 3.1 登录页

**功能描述**
用户通过手机号验证码登录系统。

**输入项**

| 字段名  | 类型 | 是否必填 | 校验规则                  |
| ---- | -- | ---- | --------------------- |
| 手机号码 | 文本 | 是    | 11位数字，格式为1\[3-9]\d{9} |
| 验证码  | 文本 | 是    | 6位数字                  |

**输出/反馈**

- 登录成功：跳转到业务需求列表页
- 登录失败：显示错误提示信息
- 新用户自动注册并提示

**业务规则**

- 未注册用户登录时自动创建账号
- 验证码有效期60秒，支持重新发送
- 点击服务条款/隐私政策可查看详细内容

### 3.2 编制业务需求

#### 3.2.1 业务需求列表页

**功能描述**
展示所有业务需求列表，支持筛选、搜索和操作。

**列表展示字段**

| 字段名  | 说明               |
| ---- | ---------------- |
| 项目名称 | 业务需求关联的项目名称      |
| 项目类型 | 工程类/货物类/服务类及其子分类 |
| 项目预算 | 项目预算金额（万元）       |
| 需求状态 | 进行中/已完成          |
| 完成进度 | 进度百分比            |
| 创建时间 | 创建时间             |

**操作说明**

| 操作 | 说明           |
| -- | ------------ |
| 查看 | 查看业务需求详情     |
| 删除 | 删除业务需求，需二次确认 |

**业务规则**

- 列表支持按项目名称搜索
- 支持按需求状态筛选

#### 3.2.2 业务需求新增页

**功能描述**
创建新的业务需求，支持AI辅助生成内容。

**输入项**

| 字段名      | 类型   | 是否必填 | 校验规则            |
| -------- | ---- | ---- | --------------- |
| 项目名称     | 文本   | 是    | 长度1-100字符，不可重复  |
| 项目类型     | 下拉选择 | 是    | 工程类/货物类/服务类及其zi |
| 项目预算     | 数字   | 是    | 正数，单位万元         |
| 项目基本情况描述 | 文本域  | 否    | 长度≤500字符        |

**历史业务需求匹配**

业务需求新增页支持三种匹配模式，用户可选择不同方式生成业务需求：

| 匹配模式   | 说明                   |
| :----- | :------------------- |
| 系统自动匹配 | 系统根据历史信息自动匹配，生成业务需求  |
| 手动选择   | 从历史业务需求库中手动选择匹配度高的文件 |
| 上传     | 上传本地业务需求文件           |

**模式1：系统自动匹配**

- 系统根据当前填写的项目信息自动匹配历史业务需求
- 自动生成业务需求内容
- 无需用户手动干预

**模式2：手动选择**

展示历史文件库中匹配度高的文件列表，支持以下功能：

| 功能 | 说明               |
| :- | :--------------- |
| 预览 | 查看历史业务需求详情       |
| 选择 | 选择该历史文件作为参考生成新需求 |

- 文件卡片展示匹配度信息（如：95% - 与当前需求相似度较高，通过，）
- 仅支持单选
- 文件按匹配度从高到低排序，最多支持5个

**模式3：上传**

支持上传本地业务需求文件：

| 字段   | 说明       |
| :--- | :------- |
| 文件格式 | DOC/DOCX |
| 文件大小 | 不超过50MB  |
| 数量限制 | 单次上传1份文件 |

<br />

**输出/反馈**

- 创建成功后跳转到业务需求列表页
- 表单校验失败显示错误提示

**业务规则**

- 项目名称需唯一
- 项目预算必须为正数

#### 3.2.3 业务需求编辑页

**功能描述**
编辑已有业务需求，保留原填写内容可修改。

**输入项**

- 同新增页字段，预填充原有数据

**输出/反馈**

- 修改成功后提示保存成功
- 支持取消操作返回列表

**业务规则**

- 所有字段均可修改
- 修改后保持数据一致性

#### 3.2.4 业务需求生成页

**功能描述**
使用AI助手生成业务需求内容，支持对话式微调。

**输入项**

- 用户输入的自然语言指令

**输出/反馈**

- AI生成的业务需求内容
- 支持接受/修改/重新生成

**业务规则**

- AI助手接入互联网，有涉密信息请勿发送
- 生成内容需人工确认
- 用户在编辑器右上角可以进行保持、编辑、导出，系统应进行一定频率（比如2分钟）的自动保存

#### 3.2.5 业务需求智能检测页

**功能描述**
对业务需求进行智能检测，包含敏感词和错别字检查。

**检测项**

| 检测类型  | 说明        |
| ----- | --------- |
| 敏感词检测 | 检测并标记敏感词汇 |
| 错别字检查 | 检测并标记错别字  |

**操作说明**

| 操作   | 说明               |
| ---- | ---------------- |
| 接受建议 | 自动修正检测到的问题       |
| 拒绝建议 | 保留原文，不进行修改       |
| 查看原文 | 查看问题所在的原文位置，高亮显示 |

**输出/反馈**

- 检测结果列表，包含问题位置和建议
- 修正后的文档内容

**业务规则**

- 检测结果以卡片形式展示
- 每个问题支持单独处理

#### 3.3.2 项目创建页

**功能描述**
创建新的招标项目，支持从第三方系统跳转创建。

**输入项**

| 字段名  | 类型    | 是否必填 | 校验规则                                                     |
| ---- | ----- | ---- | -------------------------------------------------------- |
| 项目编号 | 文本    | 是    | 长度1-50字符，不可重复                                            |
| 项目名称 | 文本    | 是    | 长度1-100字符，不可重复                                           |
| 项目类别 | 下拉选择  | 是    | 限额以下/产权交易/政府采购                                           |
| 项目类型 | 下拉选择  | 是    | 工程类/货物类/服务类(物业、IT服务、咨询服务、维保服务)，模拟数据示例（非真实要做的类型）          |
| 项目预算 | 数字    | 是    | 正数，保留2位小数，单位万元                                           |
| 评审方式 | 单选    | 是    | 智能评审、人工评审。若是智能评审，评审项只需设置符合性审查内容                          |
| 招标需求 | 单选+文本 | 是    | 支持模式1：引用（选择业务需求项目或直接录入），引用到业务需求可修改；模式2：系统生成（输入项目描述由系统生成） |

**招标需求选择**

招标需求支持两种模式：

| 模式       | 说明                   |
| -------- | -------------------- |
| 模式1：引用   | 选择已有业务需求或直接录入招标需求内容  |
| 模式2：系统生成 | 输入项目描述，由系统AI生成招标需求内容 |

**模式1：引用**

包含两种来源选择：

| 来源            | 说明                           |
| ------------- | ---------------------------- |
| 选择编制业务需求模块的项目 | 从已定稿的业务需求项目中选择，展示其定稿内容供预览和引用 |
| 直接录入          | 用户直接输入招标需求内容                 |

- 选择业务需求项目后，系统展示已定稿的业务需求内容预览
- 支持查看业务需求详情

**模式2：系统生成**

- 用户输入项目描述文本
- 系统根据项目描述自动生成招标需求内容
- 生成结果展示在页面上，供用户确认和修改

**输出/反馈**

- 创建成功后跳转到文件编制流程（基本信息录入阶段）
- 表单校验失败显示错误提示

**文件编制流程（中间流程）**

项目创建成功后，进入文件编制五阶段流程：

项目列表 → 创建项目/第三方跳转 → 项目详情 → 项目需求
→
评审项设置 → 文档集成 → 智能检测&#x20;

| 阶段        | 页面                                 | 功能说明                                                                                                                                                                                                        | 其他展示内容                                                                                                                                                         |
| --------- | ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1. 基本信息录入 | business-requirement-create.html   | 引用创建的项目名称、项目基本情况描述等信息，选择招标文件模板，匹配历史参考招标文件，内容同编制业务需求模块的新建页面。支持三种匹配模式：系统自动匹配、手动选择历史文件、上传本地文件。                                                                                                                 | <br />                                                                                                                                                         |
| 2. 详细需求生成 | business-requirement-generate.html | 若引用，直接引用可修改。若自动生成基于基本信息及参考信息及后台的训练数据生成。                                                                                                                                                                     | AI助手对话框；生成后支持对内容进行"赞"或"不行"的选择性操作，标记后AI可根据反馈进行优化调整。每次完全重新生成后可标记。（评审项设置模块同）                                                                                      |
| 3. 评审项设置  | project-review\.html               | 系统基于基于基本信息、分值区间建议、及参考信息及后台的训练数据，生成评审指标和评分标准，配置评审项权重和评分规则。用户可增、删、改。包含四类评审内容：①符合性审查（评审标准）；②技术标评审（评审标准\[支持三级]、评审分值、客观/主观）；③资信标评审（评审标准\[支持三级]、评审分值、客观/主观）；④商务评审（评审标准及满分值）。每项可配置分值、权重及是否为必选项。                    | AI助手对话框；生成后支持对内容进行"赞"或"不行"的选择性操作，标记后AI可根据反馈进行优化调整。每次完全重新生成后可标记。（评审项设置模块同）；页面展示【\*\*评分建议：\*\*建议货物类项目商务分30-60，资信10-25分；建议服务类项目商务分10-30，资信10-25分。】，也做为AI生成参考分值的依据 |
| 4. 文档集成   | 文档集成页                              | 将生成的需求文档与招标文件模板进行集成，生成完整的招标文件初稿。支持预览集成效果，可对文档进行整体调整和编辑。                                                                                                                                                     | <br />                                                                                                                                                         |
| 5. 智能检测   | business-requirement-review\.html  | 对招标文件进行全面智能检测。弹出政策选择框，两部分：1.当前项目类别匹配到的启用状态平台政策文件，默认你打勾可取消；2.当前项目类别匹配到的启用状态用户自行上传的政策文件。进行选择。包含：①敏感词检测（检测并标记敏感词汇）；②错别字检测（检测并标记错别字）；③政策文件审查（可选择相关政策文件进行合规性检查）；④格式规范检测。每个检测项提供修改建议，支持单条接受/拒绝建议，也支持一键接受所有建议批量修正。 | <br />                                                                                                                                                         |

**业务规则**

### 3.6 平台通用AI助手

**功能描述**
平台通用AI助手位于页面右侧，提供智能辅助功能，支持自然语言交互，帮助用户完成招标文件编制相关任务。

**位置与形态**

- 固定显示在页面右侧
- 默认状态为折叠的圆形图标
- 点击展开聊天窗口

**功能特性**

| 功能   | 说明             |
| ---- | -------------- |
| 智能生成 | 根据用户输入生成招标文件内容 |
| 内容优化 | 对已选择的内容进行优化和润色 |
| 问题解答 | 解答招标相关的常见问题    |
| 格式整理 | 整理文档格式，使其符合规范  |

**交互方式**

| 操作   | 说明             |
| ---- | -------------- |
| 点击图标 | 展开/收起聊天窗口      |
| 输入文本 | 在输入框中输入问题或指令   |
| 选择文本 | 选择页面上的文本，在输入需求 |
| 发送消息 | 点击发送按钮或按回车键    |
| 快捷选项 | 点击预设的快捷选项按钮    |

**安全提示**

- AI助手接入互联网，有涉密信息请勿发送
- 在聊天窗口顶部显示橙色安全提示："AI助手接入互联网，若有涉密信息请勿发送"

**输出/反馈**

- AI生成的回复内容
- 支持复制生成的内容
- 支持重新生成

**业务规则**

- AI生成内容需人工确认后使用
- 敏感信息不会被发送到AI服务器
