# 文档预览改造与前端验证设计

> 日期: 2026-04-22
> 状态: 已确认
> 前置: 模板模块重构已完成（端到端验证通过）

---

## 背景

模板模块重构后，文档生成从 Markdown 硬编码改为 Word 模板填充（poi-tl）。后端已返回 `generatedFileId`，但前端仍有两处不一致：

1. `DocumentPreview.vue` 仍用 `v-html` 渲染 HTML（来自旧 Markdown 流程）
2. 支撑前端上传和业务前端绑定流程未经完整 UI 验证

## 目标

1. 将 `DocumentPreview.vue` 从 HTML 预览改造为 docx-preview 渲染
2. 提取 `DocxPreview.vue` 公共组件，消除与 `PhaseDocument.vue` 的渲染逻辑重复
3. 启动服务验证支撑前端上传流程和业务前端模板绑定流程

## 约束

- 不改后端 API
- 不做文档内联编辑（editContent 保留但不调用）
- 未集成的文档禁止点击预览

---

## 设计

### 1. DocxPreview 公共组件

**路径**: `src/components/document/DocxPreview.vue`

**职责**: 接收 fileId，下载 Word 文件并渲染

**Props**:

| Prop | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| fileId | number \| null | null | 要预览的文件 ID |
| zoom | number | 100 | 缩放比例 |

**功能**:
- 下载文件（`fileApi.download(fileId)`）
- `renderAsync` 渲染（breakPages, ignoreFonts=false 等配置，从 PhaseDocument 提取）
- 加载状态（v-loading）
- 错误处理（渲染失败提示 + 回退下载建议）
- 缩放（CSS transform，由 zoom prop 控制）

**不包含**: TOC 面板、打印按钮、下载按钮——由使用方自行决定

### 2. DocumentPreview.vue 改造

**改动前**: 弹窗 → `getPreview()` → `v-html="previewData.htmlContent"`

**改动后**: 弹窗 → 检查 `integrated` → 已集成则用 `generatedFileId` + `DocxPreview` 渲染

**预览逻辑**:
```
打开弹窗 → 检查 integrated
  → false: 预览按钮禁用，提示"请先完成文档集成"
  → true: 用 generatedFileId 渲染 Word 预览
```

**变更清单**:

| 项 | 改动 |
|------|------|
| 模板 | 移除 v-html，替换为 `<DocxPreview :file-id="generatedFileId" />` |
| 数据获取 | 调用 `getPreview()` 只取 `generatedFileId` 和 `integrated` |
| 编辑按钮 | 移除内联编辑功能 |
| API 依赖 | 不再依赖 `htmlContent` / `markdownContent` |

### 3. PhaseDocument.vue 重构

**提取出去**: renderDocxPreview()、docxPreviewContainer ref、isDocxLoading、renderAsync 配置

**替换为**:
```vue
<DocxPreview :file-id="generatedFileId" :zoom="zoomLevel" />
```

**保留在 PhaseDocument**: TOC 面板、缩放控制条、打印/下载按钮、集成状态管理、集成触发按钮

### 4. 支撑前端上传验证

启动支撑中心前端 + 后端服务，完整测试 Word 模板上传流程：

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 登录支撑中心 | 成功进入管理后台 |
| 2 | 进入模板管理 | 列表正常加载 |
| 3 | 新建模板 | 弹出表单，含文件上传控件 |
| 4 | 填写名称、类别、类型 | 校验通过 |
| 5 | 上传 .docx 文件 | 上传成功，返回 fileId |
| 6 | 提交创建 | structureDefinition 自动填充 |

| 9 | 删除模板 | 逻辑删除 |

**重点**: 文件上传大小/类型提示、上传失败错误提示、structureDefinition 回显

### 5. 业务前端模板绑定验证
