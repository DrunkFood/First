# 评审项多级手动录入功能设计

## 问题描述

评审项设置页面不支持手动录入，根本原因：
1. `PhaseReviewItem.vue` 的 `loadReviewItems` 方法过滤掉了 `level=1` 的评审项（第283行）
2. `handleAddItem` 创建新项时固定 `level: 1`，创建后立即被过滤隐藏
3. 前端只有扁平表格展示，无法添加子级评审项，无法展示层级关系

## 设计方案

### 方案选择

采用 **el-table + tree-props** 方案，基于 Element Plus 原生树形表格能力实现。

理由：改动最小，复用现有4个Tab + el-table结构，el-table原生支持树形数据。

### 层级约束

最多三级，可灵活少用：
- 一级：分类（如"企业资质"）
- 二级：大类（如"营业执照"）
- 三级：叶子评审项（如"营业执照有效性"，含分值、主客观属性）

## 数据流改造

### Bug 修复

1. `loadReviewItems`：移除 `.filter((item) => (item.level ?? 1) > 1)` 过滤，接收全部数据
2. `handleAddItem`：创建评审项时 `level` 基于父级计算，默认创建顶级(level=1)

### 数据组装

```
后端返回扁平列表 → 前端按 parentId 组装树形结构 → 按 reviewType 分 Tab 展示
```

### 评分计算

只统计**叶子节点**的分值，非叶子节点（分类行）的分值由子节点自动汇总。

## 树形表格 UI 交互

### 表格结构（以资信评审为例）

```
序号 | 评审标准              | 主观/客观 | 分值 | 操作
─────┼──────────────────────┼──────────┼──────┼──────────────────
     | ▼ 一、企业资质       |          | 10   | ➕🗑
     |   ▼ 1.1 营业执照     |          |  5   | ➕🗑
     |     1.1.1 有效性     | 客观     |  5   |      🗑
     |   ▼ 1.2 资质等级     |          |  5   | ➕🗑
     |     1.2.1 甲级资质   | 客观     |  3   |      🗑
     |     1.2.2 乙级资质   | 主观     |  2   |      🗑
─────┼──────────────────────┼──────────┼──────┼──────────────────
     |  + 添加评审项
```

### 操作按钮规则

| 节点层级 | 添加子项(➕) | 删除(🗑) | 可编辑字段 |
|---------|-------------|---------|-----------|
| 一级(分类) | 有（最多到3级） | 有（级联删除子项） | 评审标准名称 |
| 二级(大类) | 有（最多到3级） | 有（级联删除子项） | 评审标准名称 |
| 三级(叶子) | 无 | 有 | 评审标准名称、主观/客观、分值 |

### 关键交互

- **添加子项**：点击 ➕ 按钮 → 在该节点下创建 level+1 子项，名称默认为空（占位提示"请输入评审标准"）
- **底部"添加评审项"**：保留，创建顶级(level=1)评审项
- **分值汇总**：非叶子节点的分值由子节点自动汇总，不可直接编辑
- **排序**：暂不实现拖拽排序，后续可扩展

## 后端改动

### 需要改动

1. **`ReviewItemServiceImpl.create`**：增加 level 自动计算和层级校验
   - 如果传了 parentId，自动根据父节点的 level + 1 设置 level
   - 校验最大层级不超过 3
   - 约10行代码

### 不需要改动

- 数据库表结构（已有 parentId、level 字段和索引）
- 删除接口（已支持级联删除）
- 批量创建/更新接口
- Controller 接口定义

## 前端改动

### PhaseReviewItem.vue 主要改动

1. **数据加载**：移除 level 过滤，改为组装树形数据
2. **数据组装工具函数**：新增 `buildTree(flatList)` 将扁平列表转为树形
3. **表格结构**：为 el-table 添加 `row-key="id"` 和 `tree-props="{ children: 'children', hasChildren: 'hasChildren' }"`
4. **分值列**：叶子节点显示可编辑输入框，非叶子节点显示汇总值（只读）
5. **主观/客观列**：仅叶子节点显示选择框
6. **操作列**：非叶子节点增加"添加子项"按钮，叶子节点仅删除
7. **handleAddItem**：支持传入 parentId，自动计算 level
8. **评分汇总**：computed 只累加叶子节点的 score
