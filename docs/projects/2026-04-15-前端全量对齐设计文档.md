# 前端全量对齐设计文档

> 日期：2026-04-15 | 状态：已确认 | 参考：需求文档V1.0 + 原型设计HTML

## 一、背景与目标

当前 `ele-ai-tender-frontend` 前端页面与需求文档和原型设计严重不符：

- **10个原型页面完全缺失**（模板管理4页、统计分析、系统设置、需求生成、需求检测、项目编辑）
- **5个页面高度不完整**（项目详情3个空Tab、首页硬编码0、需求编辑仅textarea、政策文件上传对话框缺失、项目创建编辑模式未实现）
- **侧边栏导航与原型不匹配**（命名不一致、多余菜单项、缺失模块）
- **AI模块10个API全部未接入**前端
- **Core模块7个API未接入**（项目生命周期5个 + 需求检测/匹配2个）

**目标**：一次性全量对齐需求文档V1.0，使前端功能、页面结构、交互体验与需求一致。

## 二、范围决策

| 决策项 | 结论 | 理由 |
|--------|------|------|
| 统计分析 | 排除 | 需求文档V1.0明确排除 |
| 消息中心 | 保留并完善 | 已有基础实现，用户要求保留 |
| 系统设置 | 排除 | 需求文档V1.0明确排除 |
| 模板管理 | 放 support-frontend | 需求明确"仅管理员可用" |
| AI助手 | 页面内嵌AI对话 | 不做全局浮动组件 |
| 登录默认页 | 业务需求列表 | 需求定义的首页 |
| 独立 ReviewEditor | 移除 | 功能合并到向导 PhaseReviewItem |

## 三、侧边栏导航重构

### 当前结构 → 目标结构

```
- 首页                    →  - 业务需求管理
- 招标文件管理                ├── 业务需求列表
  - 项目列表        →  - 招标文件管理
  - 新建项目                ├── 项目列表
- 业务需求管理      →  - 政策文件管理
  - 需求列表        →  - 消息中心
  - 新建需求
- 政策文件管理
- 消息中心          →  保留

变更：移除首页菜单（登录重定向到需求列表）；移除"新建项目/新建需求"一级菜单（改为列表页按钮）；保留消息中心；命名对齐需求文档。

**目标**：

筛选区：需求名称 | 需求状态(下拉) | 项目类型(下拉) | 创建时间(日期范围) | 查询 | 重置
表格列：checkbox | 需求名称(链接→编辑页) | 项目类型(彩色badge) | 项目预算 | 完成进度(进度条) | 创建时间 | 操作(查看/生成/检测/删除)
```

新增：状态彩色badge、生成/检测操作入口、4项筛选条件、预算和进度列。

#### RequirementCreate.vue — 完善

新增：AI辅助生成开关、上传模式文件上传组件。

#### RequirementEditor.vue — 重写

```
顶部工具栏：保存 | AI生成 | 提交检测 | 返回
左侧：MarkdownEditor
右侧(可折叠)：AiChatPanel AI对话面板
底部：自动保存状态 + 最后保存时间
```

核心：替换textarea为MarkdownEditor、AI生成按钮(SSE流式)、内嵌AI对话、2分钟自动保存、草稿恢复。

#### RequirementGenerate.vue — 新建

```
顶部：需求名称 + 状态标签 + 保存/导出
左侧：AI生成内容区(Markdown渲染，逐段流式显示) + 编辑切换(MarkdownEditor)
右侧：AiChatPanel(对话+赞/不行反馈)
底部：保存草稿 | 提交审核 | 返回
```

核心：SSE流式接收、赞/不行反馈、人工审核确认(GENERATING→PENDING_REVIEW)、自动保存。

#### RequirementDetect.vue — 新建

```
顶部：需求名称 + 检测状态
检测类型卡片(2个)：敏感词检测 | 错别字检测（各含进度+结果数）
结果区(卡片式)：检测类型标签 | 严重程度 | 原文高亮 | AI建议 | 接受/拒绝
底部：批量接受 | 返回修改
```

核心：调用`POST /requirements/{id}/detect`、轮询进度、逐条/批量处理。

## 八、交互规范

### 状态/类型彩色Badge

**项目状态**：DRAFT→info"草稿" | IN_PROGRESS→primary"编制中" | PENDING_DETECTION→warning"待检测" | DETECTING→primary脉冲"检测中" | DETECTION_PASSED→success"检测通过" | DETECTION_FAILED→danger"检测失败" | PUBLISHED→success"已发布" | ARCHIVED→info"已归档" | CANCELLED→info"已取消"

**需求状态**：DRAFT→info"草稿" | GENERATING→primary脉冲"生成中" | PENDING_REVIEW→warning"待审核" | APPROVED→success"已通过" | REJECTED→danger"已拒绝"

**项目类别**：LIMITED_BELOW→primary"限额以下" | PROPERTY_TRADE→warning"产权交易" | GOVERNMENT_PROCUREMENT→success"政府采购"

**项目类型**：ENGINEERING→#336CFF"工程" | GOODS→#31E3FD"货物" | SERVICE→#FF8D3B"服务"

### 通用交互

- 删除操作二次确认弹窗
- 表单提交loading状态
- 操作成功/失败ElMessage提示
- AI生成内容需人工审核机制
- SSE流式响应使用EventSource接收
