# 评审项生成期间禁用编辑 — 设计文档

## 需求

AI生成评审项期间，前端禁用全部编辑操作（修改名称、分值、主观/客观、添加子项、删除、添加顶级项），防止用户修改与AI生成产生冲突。

## 现状分析

- `PhaseReviewItem.vue` 已有 `readonly` prop 控制编辑权限
- `useLatestTask('REVIEW_ITEM_GENERATE', ...)` 已提供 `latestTask` 状态
- 生成状态：`PENDING` / `PROCESSING` = 生成中，`COMPLETED` / `FAILED` / `AI_UNAVAILABLE` / `SKIPPED` = 终态
- 当前所有编辑控件仅受 `readonly` 控制，未关联生成任务状态

## 方案

在 `PhaseReviewItem.vue` 中新增 `isGenerating` computed，与 `readonly` 叠加控制所有编辑控件。

### 核心逻辑

```typescript
const isGenerating = computed(() => {
  const status = latestTask.value?.status
  return status === 'PENDING' || status === 'PROCESSING'
})

// 统一禁用条件
const isEditingDisabled = computed(() => readonly || isGenerating.value)
```

### 不改动的部分

- `GenerationStatusCard` — 已有生成中提示，无需改动
- 后端 — 不加校验
- 其他阶段组件 — 不涉及

### 提示增强

生成期间禁用的输入框 hover 时通过 `el-tooltip` 显示提示文案："评审项正在生成中，请稍候"。

## 预期行为

| 场景 | 行为 |
|------|------|
| 无生成任务 | 正常编辑 |
| 生成中(PENDING/PROCESSING) | 全部编辑控件禁用，hover显示提示 |
| 生成完成(COMPLETED) | 自动刷新数据，恢复编辑 |
| 生成失败(FAILED/AI_UNAVAILABLE) | 恢复编辑 |
| readonly=true | 始终禁用（优先级更高） |
