# 2026-03-24 最终招标文件版本字段配置化需求整理

## 背景
当前最终招标文件中的 `versionInfo` 字段存在硬编码：
- `tenderDocumentFormatVersion = "0.0.1"`
- `tenderDocumentAppVersion = "0.0.1"`

## 本次需求
将以下字段改为从配置文件读取：
1. `tenderDocumentAppVersion`（注释：招标文件编制系统版本号，整数上升）
2. `tenderDocumentFormatVersion`（注释：招标文件格式版本号，格式：`(格式版本号)_(招标系统版本号)_(自定义)`）

`TenderDocumentUniqueCode` 保持现有生成逻辑（随机唯一编码）不变。

## 影响范围
- 模块：`ele-tender-system/ele-tender-tender-document`
- 代码：最终数据包 `versionInfo` 组装逻辑
- 配置：`application.yml` / 本地覆盖配置
- 测试：`TenderDocumentGenerationServiceTest`

## 验收标准
- 生成时 `versionInfo.tenderDocumentAppVersion` 与 `versionInfo.tenderDocumentFormatVersion` 来自配置项。
- 默认配置可用，不配置时系统可正常启动并生成。
- 现有生成流程测试通过，新增用例覆盖“配置值生效”。
