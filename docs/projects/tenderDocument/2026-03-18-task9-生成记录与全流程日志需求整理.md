# 2026-03-18 Task9 生成记录与全流程日志需求整理

## 背景

- 当前最终招标文件生成已完成主流程（生成数据包、生成采购文件编制信息、回传拆分）。
- 需补齐“可查询、可审计”的生成过程留痕能力。

## 本次需求

- 生成按钮每次触发都新增一条独立生成记录，不覆盖历史。
- 记录状态流转：`PROCESSING -> SUCCESS/FAIL`。
- 失败记录需要保留错误码与错误信息。
- 生成链路增加结构化日志，便于按 `traceId + tenderDocumentId` 排障。

## 设计约束

- 生成记录使用独立数据表持久化，后续支持分页查询。
- 记录写入采用独立事务，避免主事务回滚导致审计信息丢失。
- 不改变“生成接口与回传接口分离”的现有行为。

## 验收要点

- 成功生成：存在 `PROCESSING` 记录并最终更新为 `SUCCESS`。
- 失败生成：存在 `PROCESSING` 记录并最终更新为 `FAIL`，且带错误信息。
- 多次生成尝试保留多条历史记录，可按时间倒序查询。
