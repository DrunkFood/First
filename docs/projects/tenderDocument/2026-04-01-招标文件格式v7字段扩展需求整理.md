# 2026-04-01 招标文件格式 v7 字段扩展需求整理

## 1. 背景

招标文件格式讨论版 v7（`/Volumes/JyFile/电子标/招投标文件格式_讨论版_v7.md`）在 `.HzctZbs` 文件的 `baseInfo` 中新增了 5 个字段，需要同步更新系统各层实现。

## 2. v7 新增字段清单

### 2.1 项目级字段（`baseInfo` 下）

| 字段名 | 类型 | 说明 |
|---|---|---|
| `purchaserName` | String | 采购单位名称 |
| `purchaseMethod` | String | 采购方式中文名，如"公开招标"、"邀请招标" |
| `bidEndTime` | String | 投标截止时间，格式 `yyyy-MM-dd HH:mm:ss` |

### 2.2 标段级字段（`baseInfo.tendersInfo[]` 下）

| 字段名 | 类型 | 说明 |
|---|---|---|
| `tenderAmount` | BigDecimal(18,2) | 标段标的金额 |
| `purchaseContext` | String | 采购内容 |

## 3. 设计决策

### 3.1 purchaseWay → purchaseMethod 字段名统一

v7 格式文档中该字段名为 `purchaseWay`，但与现有系统中 `ProjectBasicInfoResponse.purchaseMethod` 语义完全相同（均为采购方式中文展示值）。统一使用 `purchaseMethod` 作为最终包中的字段名，避免引入多余字段名。

### 3.2 tenderAmount / purchaseContext 已在协议层存在

这两个字段在 `ProjectTenderInfo` 中已存在，且已通过 `InteractionTenderDocumentSyncGateway.appendTenderList()` 写入快照。本次只需在 `FinalPackagePayload.TenderInfo` 中新增字段并在 `FinalPackageDataAssembler.toTenderInfo()` 中读取输出。

### 3.3 purchaserName / bidEndTime 的存储策略

采用 snapshot 透传方式：
- `ProjectBasicInfoResponse` 新增两个字段
- `InteractionTenderDocumentSyncGateway.mapBasicInfo()` 将其写入 `projectInfo` Map 存入快照
- 打包时 `FinalPackageDataAssembler.buildBaseInfo()` 从快照读取
- `CompileInfoPdfGenerator` 也从快照的 `projectInfo` 中读取，无需新增 DB 列

## 4. 影响范围

### 代码变更

| 文件 | 变更内容 |
|---|---|
| `ele-tender-common-interaction/.../dto/ProjectBasicInfoResponse.java` | 新增 `purchaserName`, `bidEndTime` 字段 |
| `ele-tender-tender-document/.../model/generation/FinalPackagePayload.java` | `BaseInfo` 新增 3 字段，`TenderInfo` 新增 2 字段 |
| `ele-tender-tender-document/.../support/interaction/InteractionTenderDocumentSyncGateway.java` | `mapBasicInfo()` 写入新字段到 projectInfo map |
| `ele-tender-tender-document/.../support/DefaultTenderDocumentSyncGateway.java` | 更新 `buildProjectInfo()` / `buildTenderInfo()` stub 数据 |
| `ele-tender-tender-document/.../support/generation/FinalPackageDataAssembler.java` | `buildBaseInfo()` / `toTenderInfo()` 读取新字段，新增 `toBigDecimal()` 工具方法，暴露 `readBasicInfoProjectInfo()` |
| `ele-tender-tender-document/.../support/generation/CompileInfoPdfGenerator.java` | `generate()` / `buildModel()` 新增 `projectInfo` 参数，baseInfoLines 新增"采购单位名称"行 |
| `TenderDocumentGenerationServiceImpl.java` | 调用 PDF 生成前读取快照 projectInfo 并传入 |

### DB 变更

无。新字段通过 snapshot JSON 透传，不新增数据库列。

### 协议兼容性

`ProjectBasicInfoResponse` 新增字段为可选（无 validation 注解），业务系统 SPI 实现不返回时字段为 null，最终包中对应字段为 null/缺失，不影响已有功能。
