# 本地加解密工具需求整理

## 目标

- 提供一个可直接对本地指定文件执行加密/解密的工具，便于日常联调与验证。
- 工具应复用系统当前最终数据包加密规则，避免测试结果与生产链路不一致。

## 需求点

- 支持命令行模式：
  - `encrypt <input> <output> <base64Key> [algorithm]`
  - `decrypt <input> <output> <base64Key> [algorithm]`
- 默认算法为 `AES/GCM/NoPadding`。
- 加密输出与系统最终数据包格式一致（`HZPK + version + nonce + ciphertextTag`）。

## 验收

- 可以对本地文件加密后再解密还原。
- 错误参数时返回非 0 状态码并打印提示。
