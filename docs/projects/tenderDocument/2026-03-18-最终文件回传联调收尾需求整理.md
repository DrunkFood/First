# 2026-03-18 最终文件回传联调收尾需求整理

## 背景
- 当前 `ele-tender-tender-document` 已具备统一回传入口 `/api/tender-documents/generate/callback`，可向业务系统回传 `SIGNED_PDF` 与 `FINAL_PACKAGE_FILE`。
- 当前 demo 业务系统回调 SPI 仅做内存留痕，未形成“收到 fileId 后主动查询/下载文件”的真实闭环。

## 本次需求
- 用户要求“开始做最后的文件回传工作”，并选择优先事项 `1`：联调打通（真实调用业务系统）。

## 目标
- 在 demo 业务系统中实现回调后自动调用交互客户端完成文件查询与下载。
- 在回传记录中补充下载结果字段，支持联调可视化排查。
- 通过最小测试验证：回调触发 -> 文件信息查询/下载被调用 -> 记录可查询。

## 范围
- `ele-tender-demo-business-system`：模型、SPI实现、测试。
- 不改动电子标主业务回传协议字段，不新增跨系统接口。

## 验收标准
- 回调接口仍返回成功结构。
- 回调后会尝试调用 `EleTenderInteractionClient.getFileInfo(fileId)` 和 `downloadFile(fileId)`。
- `/api/demo/callback-records` 可看到下载状态与错误信息（若失败）。
