# 对话上下文：需求完成状态查看检测页

> 生成时间：2026-04-23 | 状态：已解决

---

## 📋 问题背景

**项目**：招标文件AI编制工具（ele-ai-tender-frontend）

**涉及模块**：业务需求模块 — 需求生成页 + 智能检测页

**业务流程**：
1. 用户创建业务需求 → 进入 AI 生成页（RequirementGenerate）
2. 生成完成后 → 进入智能检测页（RequirementDetect）
3. 检测通过/跳过 → 需求状态变为 COMPLETED

**当前状态**：需求状态 COMPLETED 后，生成页隐藏了"下一步：智能检测"按钮，用户无法再查看检测页面。检测页虽有路由但无法从 UI 到达。

## 🔴 核心问题

需求状态为 COMPLETED 时，无法查看智能检测页面：

- `RequirementGenerate.vue`：COMPLETED 状态下底部只显示"返回列表"按钮
- `RequirementDetect.vue`：COMPLETED 状态下若未提交过检测，仍显示"跳过检测"/"开始智能检测"操作按钮，不符合只读查看语义
- 检测问题列表中"接受建议"/"拒绝建议"按钮在 COMPLETED 状态下仍可操作

## 🎯 实现目标

1. COMPLETED 状态下可从生成页导航到检测页（只读查看）
2. 检测页在 COMPLETED 状态下为只读模式，隐藏修改性操作
3. 清理无意义的"返回修改"按钮

## 🔧 技术约束

- 需求状态枚举：`DRAFT` / `GENERATING` / `PENDING_REVIEW` / `APPROVED` / `REJECTED` / `COMPLETED`
- 判断方式：`requirementData.value.status === 'COMPLETED'`
- 路由：`/requirement/generate/:id` → `/requirement/detect/:id`
- 检测页已有 `isRequirementCompleted` 计算属性

## ✅ 最终方案

### 1. RequirementGenerate.vue — 底部操作栏调整

**修改前**：
```
[返回修改] [返回列表(COMPLETED)] / [下一步：智能检测(非COMPLETED)]
```

**修改后**：
```
[返回列表(COMPLETED)] [查看智能检测(COMPLETED)]
[返回列表(非COMPLETED)] [下一步：智能检测(非COMPLETED)]
```

- 删除"返回修改"按钮（`router.back()` 语义模糊，与顶部"返回列表"重复）
- COMPLETED 状态增加"查看智能检测"主按钮
- 两种状态都提供"返回列表"按钮，统一用 `router.push('/requirement')`

### 2. RequirementDetect.vue — 只读模式

**初始状态（无检测记录）**：
- COMPLETED：显示"该需求已完成，暂无检测记录" + "返回需求"按钮
- 非COMPLETED：显示"跳过检测" / "开始智能检测"

**检测问题列表**：
- COMPLETED + 未处理问题：隐藏"接受建议"/"拒绝建议"，显示"未处理"标签
- 非COMPLETED + 未处理问题：显示"接受建议"/"拒绝建议"按钮

**已有机制（无需修改）**：
- "重新检测"按钮：`canReDetect` 已排除 COMPLETED
- "跳过检测"/"完成检测"：已有 `v-if="!isRequirementCompleted"` 控制
