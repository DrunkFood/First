# 对话上下文：评审项多级手动录入

> 生成时间: 2026-04-28 | 状态: **待确认**（代码已提交，未在运行环境验证）

---

## 📋 问题背景

**项目**: 招标文件AI编制工具（ele-ai-tender）
**涉及模块**: ele-ai-tender-core（后端评审项服务）、ele-ai-tender-frontend（前端评审项页面）
**涉及组件**: `ReviewItemServiceImpl`、`PhaseReviewItem.vue`、`review.ts`

项目管理中的评审项设置页面不支持手动录入，也无法展示多级层级结构。

---

## 🔴 核心问题

### 问题表现
1. 点击"添加评审项"按钮后，页面无任何变化——评审项创建了但看不到
2. 前端只有扁平表格展示，无法添加子级评审项，无法展示层级关系

### 根源分析
- **Bug根因**: `PhaseReviewItem.vue` 第283行 `loadReviewItems` 方法中 `.filter((item) => (item.level ?? 1) > 1)` 把 `level=1` 的评审项全部过滤掉了
- **而 `handleAddItem`** 第318行创建新项时固定 `level: 1`，导致创建后立即被过滤隐藏
- **后端实际已支持多级**（`parentId`/`level` 字段和索引都有），但前端没有利用

---

## 🎯 实现目标

1. 修复手动录入Bug——移除 level 过滤
2. 支持多级评审项（最多3级）的树形表格展示和录入
3. 支持添加子项、级联删除、分值汇总
4. 评分汇总只统计叶子节点

### 约束条件
- 层级最多3级，可灵活少用
- 4种评审类型（符合性/资信/技术/商务）保持 Tab 分组
- 各 Tab 列配置不同（符合性无分值/主观客观列，商务无主观客观列）
- 遵循现有 el-table + CSS 变量风格

---

## 🔧 技术约束

- **前端**: Vue 3 `<script setup>` + Element Plus `el-table` 的 `tree-props` 原生树形能力
- **后端**: Spring Boot 3 + MyBatis-Plus，实体直接作为请求体（既有风格）
- **subjectivity 字段**: 后端 `String`（OBJECTIVE/SUBJECTIVE），前端从 `boolean` 改为字符串保持一致
- **评分**: 资信+技术+商务合计必须=100分，符合性审查不计分

## ✅ 最终方案

### 设计思路
采用 **el-table + tree-props** 方案，基于 Element Plus 原生树形表格能力实现。改动最小，复用现有4个Tab结构。

### 核心机制

**前端数据流**:
```
后端返回扁平列表 → loadReviewItems(移除level过滤) → buildTree组装树形 → 按reviewType分Tab → el-table tree-props展示
```

**关键工具函数**:
- `buildTree(flatList)`: 按 parentId 组装树形结构
- `isLeaf(row)`: 判断是否叶子节点（无children）
- `calcNodeScore(row)`: 递归汇总叶子节点分值
- `collectLeaves(nodes)`: 收集所有叶子节点（用于评分统计）
- `MAX_LEVEL = 3`: 常量统一管理最大层级

**后端 create 方法改造**:
- 传了 `parentId` → 自动计算 `level = parent.level + 1`，校验 `childLevel <= 3`
- 子项自动继承父项 `reviewType`
- 无 parentId → `parentId` 置 null，默认 `level = 1`

**el-table 树形配置**:
```html
<el-table :data="xxxTree" row-key="id" :tree-props="{ children: 'children' }" default-expand-all>
```

**操作列规则**:
- `level < MAX_LEVEL` 时显示"添加子项"按钮
- 叶子节点显示可编辑的分值/主观客观控件
- 非叶子节点分值显示汇总值（只读），主观客观显示"—"

**保存逻辑**:
- 树形数据展平后调用 `reviewApi.batchUpdate()` 批量更新
- flatten 时包含 id/parentId/level/itemName/itemContent/sortOrder/reviewType/subjectivity/score
