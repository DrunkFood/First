# 对话上下文：AI聊天选中内容带入与替换 — 待确认

## 📋 问题背景

**项目**：招标文件AI编制工具（ele-ai-tender-frontend）
**当前状态**：待确认 — 核心功能已实现，替换操作栏已暂时隐藏，需手动验证后决定是否恢复
**涉及组件**：WysiwygEditor → RequirementGenerate → AiAssistantSidebar → AiChatPanel

## 🔴 核心问题

用户在需求生成页面选中文字后，需要将选中内容带入AI聊天面板，随消息一起发送给后端，选中内容需单独记录以便后续文本替换。

## 🎯 实现目标

1. 用户在编辑器中选中文字（≥5字符）→ 自动带入聊天面板，输入框上方显示引用块
2. 用户输入时：context = selectedText || ''（无选中则空）
3. 快捷操作时：context = selectedText || 完整内容（无选中用全文）
4. AI回复后可自动替换选中原文（需用户确认）— **暂时隐藏此功能**
5. 不选中内容时，行为与原来完全一致

## 🔧 技术约束

- 后端零改动，复用已有 `ChatRequest.context` 字段
- TipTap `useEditor` 是异步初始化，监听事件必须放在配置选项中（不能同步注册）
- `emit` 时序：必须先 emit message 再清空 selectedText，否则父组件判断失效

## 🚫 已尝试的方案（失败）

| 方案 | 问题 |
|------|------|
| 在 `useEditor()` 后用 `if (editor.value)` 同步注册 `selectionUpdate` | editor.value 此时为 null（异步初始化），监听从未生效 |
| 在 `handleAiMessage` 中用 `selectedText.value` 判断是否追加 | 时序问题：先清空 selectedText 再 emit message，判断时已是空值 |

## ✅ 最终方案

- WysiwygEditor：在 `useEditor` 配置中用 `onSelectionUpdate` 选项注册监听（与 `onUpdate` 同级）
- AiChatPanel：`emit('message', text, hadSelection)` 传递 hadSelection 标志，在清空 selectedText 之前捕获
- 替换操作栏：已实现但用 `v-if="false"` 暂时隐藏

## 💡 使用方法

启动测试环境：
```bash
cd ele-ai-tender-frontend && npx vite --mode test
```

验证要点：
1. 需求生成页面，选中编辑器中 ≥5 字符文字 → 聊天面板输入框上方出现引用块
2. 点击引用块 ✕ → 引用块消失
3. 选中文字后输入消息发送 → 引用块消失，用户气泡显示引用内容，context 为选中内容
4. 不选中文字输入消息 → 无引用块，context 为空
5. 快捷操作按钮（不选中时）→ context 为完整内容
6. 快捷操作按钮（选中时）→ context 为选中内容

## 🐛 已知问题和待解决

1. **替换操作栏已隐藏**：`v-if="false"`，恢复时改回 `v-if="msg.role === 'assistant' && msg.content && !sending && !msg.isGreeting && !msg.error && getSelectedTextForAiMsg(index)"`
2. **handleAiMessage 中 hadSelection=true 时不追加内容**：当前选中内容发送后，AI回复不会自动追加到文档末尾（预期走替换流程），但替换功能隐藏了，所以选中发送后AI回复只显示在聊天中，不会写入编辑器
