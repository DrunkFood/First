## ✅ 最终方案

### 核心设计

```
DocxPreview.vue (公共组件)
  ├── Props: fileId (number|null), zoom (number, default 100)
  ├── 功能: 下载Word文件 → renderAsync渲染 → loading/error状态
  └── 不含: TOC面板、打印、下载按钮

DocumentPreview.vue (全屏预览弹窗)
  ├── 打开时调用 getPreview() 获取 generatedFileId + integrated
  ├── integrated=true → 渲染 DocxPreview
  └── integrated=false → 显示空状态

PhaseDocument.vue (文档阶段主页)
  ├── 替换内联 renderAsync 为 DocxPreview 组件
  └── 保留: TOC面板、缩放、打印、下载

ProjectDetail.vue (项目详情页)
  └── 预览按钮添加 :disabled="!project?.generatedFileId"
```
