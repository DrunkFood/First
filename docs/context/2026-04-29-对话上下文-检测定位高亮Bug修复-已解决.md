**项目**: 招标文件AI编制工具 (ele-ai-tender)
**模块**: 智能检测子系统 — 前端检测页面

2. 实际存在 3 个独立根因，层层嵌套

---

## 🔴 核心问题

### 根因 1：CSS 选择器写死 class 名，与 docx-preview 实际渲染不匹配

`renderAsync` 的 `className: 'docx-preview-wrapper'` 选项会改变**所有**生成的 CSS class 前缀：

| 代码假设 | 实际渲染 |
|----------|----------|
| `.docx-wrapper` | `.docx-preview-wrapper-wrapper` |
| `section.docx` | `section.docx-preview-wrapper` |

选择器 `.docx-wrapper > section.docx` 全部匹配不上 → `querySelectorAll` 返回空 → 函数直接 return null

### 根因 2：scrollToAndHighlight 没有创建文本级高亮

原实现只加了极淡的 `rgba(255,152,0,0.1)` 背景色到整个段落/表格元素，没有调用 `highlightTextInElement` 生成 `<mark>` 元素。即使定位成功，用户也看不到高亮效果。

### 根因 3：预览区无高度约束，没有滚动条

flex 布局高度链断裂：
- `.wizard-body` 用了 `min-height: 600px`（允许无限撑高），而非 `flex: 1; min-height: 0`
- `.step-content` 没有 `overflow: hidden`
- 导致预览区 `clientHeight === scrollHeight === 60707px`，无滚动条
- `scrollIntoView` 滚的是 document body 而非预览面板

## 🔧 技术约束

- **docx-preview className 选项**: 会改变所有生成 class 的前缀，不可硬编码 class 名
- **结构选择器优先**: 对第三方库 DOM 查询用标签层级（`section > article`），而非 class 名
- **flex 高度链**: 每层 flex 容器/子项都必须有 `min-height: 0`，否则默认 `auto` 撑开
- **JDK 21**: `JAVA_HOME="D:/Users/admin/.jdks/openjdk-21.0.5"`

## ✅ 最终方案

### 1. DOM 选择器：结构选择器替代 class 选择器

```typescript
// 旧：硬编码 class 名，className 配置改变后失效
const sections = containerRef.value.querySelectorAll('.docx-wrapper > section.docx')
const topElements = sections[0]!.children  // 还漏了 article 层 + 只看第一页

// 新：结构选择器，与 className 配置解耦
const articles = containerRef.value.querySelectorAll('section > article')
let offset = 0
for (const article of articles) {
  const children = article.children
  if (elementIndex < offset + children.length) {
    return children[elementIndex - offset] as HTMLElement
  }
  offset += children.length
}
```

docx-preview 实际 DOM 结构：

```
.docx-preview-content              ← containerRef
  ├── <style>...
  ├── <div class="{prefix}-wrapper">
  │     ├── <section>              ← 第1页
  │     │     ├── <header>
  │     │     ├── <article>        ← 内容容器
  │     │     │     ├── <p>  (elementIndex=0)
  │     │     │     ├── <table>(elementIndex=1)
  │     │     │     └── ...
  │     │     └── <footer>
  │     ├── <section>              ← 第2页
  │     └── ...
  └── <style>...
```

### 2. scrollToAndHighlight：增加文本级 `<mark>` 高亮

```typescript
async function scrollToAndHighlight(issue) {
  // 1. 清除旧高亮
  clearHighlights()
  // 2. 创建 <mark> 文本高亮（段落/表格分支）
  if (issue.locationRef.type === 'paragraph') {
    highlightTextInElement(targetEl, issue)
  } else if (issue.locationRef.type === 'table') {
    // 在表格内查找包含原文的段落并高亮
  }
  // 3. 滚动到预览容器内（优先 scrollTo，fallback scrollIntoView）
  const scrollContainer = getScrollContainer()
  if (scrollContainer && scrollContainer !== containerRef.value) {
    scrollContainer.scrollTo({ top: scrollOffset, behavior: 'smooth' })
  } else {
    targetEl.scrollIntoView({ behavior: 'smooth', block: 'center' })
  }
  // 4. 临时背景闪烁
  targetEl.style.backgroundColor = 'rgba(255, 152, 0, 0.15)'
}
```

## 📝 备注

### 关键经验教训

1. **docx-preview `className` 选项改了所有 class** — 不可硬编码 `.docx-wrapper` / `section.docx`，必须用结构选择器
2. **docx-preview 有 `article` 包装层** — 内容元素不是 `section` 的直接子元素，是 `section > article > *`
3. **flex 布局高度链** — `min-height` 不能替代 `flex:1; min-height:0`，每层都要 `min-height:0`
4. **Write 工具重写文件时注意完整性** — 漏掉 `applyHighlights` 函数导致 `ReferenceError` 组件白屏
