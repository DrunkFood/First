# 阶段一：支撑中心完善 - 业务开发计划

## Context

招标文件AI编制工具平台已完成项目初始化，7个Maven模块框架搭建完毕。支撑中心(8080)已实现用户认证、RBAC权限、模型配置CRUD、模板管理、知识库管理、访问日志等基础功能。

**当前缺失6个模块**：系统参数管理、政策文件管理、操作日志完善、消息中心、统计分析、模型路由管理。本计划的目标是补齐这些缺失功能，使支撑中心具备完整的管理能力。

```

```

### 注解设计
```java
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface OperationLog {
    String value(); // 操作描述，如"创建用户"
}
```

### AOP切面设计要点
- `@Around` 环绕通知，拦截`@OperationLog`注解
- 从`SecurityContextHolder.getLoginUser()`获取用户信息
- 参数JSON序列化(截断2000字符)，password字段脱敏
- **异步写入**(`@Async`)，不阻塞主业务
- 异常时仍记录日志

## 模块2：系统参数管理

### 新建表 `sup_sys_parameter`

```sql
CREATE TABLE IF NOT EXISTS `sup_sys_parameter` (
    `id`            BIGINT       NOT NULL AUTO_INCREMENT,
    `param_group`   VARCHAR(50)  NOT NULL COMMENT '参数分组: SYSTEM/SWITCH/AI_RULE',
    `param_key`     VARCHAR(100) NOT NULL COMMENT '参数键',
    `param_value`   VARCHAR(2000) DEFAULT NULL COMMENT '参数值',
    `param_type`    VARCHAR(20)  NOT NULL DEFAULT 'STRING' COMMENT '值类型: STRING/NUMBER/BOOLEAN/JSON',
    `param_name`    VARCHAR(200) NOT NULL COMMENT '参数中文名',
    `description`   VARCHAR(500) DEFAULT NULL COMMENT '参数说明',
    `sort_order`    INT          NOT NULL DEFAULT 0 COMMENT '组内排序',
    `create_time`   DATETIME NOT NULL,
    `create_id`     BIGINT NOT NULL DEFAULT 0,
    `create_name`   VARCHAR(50) NOT NULL DEFAULT '',
    `modify_time`   DATETIME NOT NULL,
    `modify_id`     BIGINT NOT NULL DEFAULT 0,
    `modify_name`   VARCHAR(50) NOT NULL DEFAULT '',
    `ver`           INT NOT NULL DEFAULT 1,
    `is_delete`     TINYINT NOT NULL DEFAULT 0,
    PRIMARY KEY (`id`),
    UNIQUE INDEX `uk_param_key` (`param_key`),
    INDEX `idx_param_group` (`param_group`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='系统参数表';
```

    `create_name`   VARCHAR(50) NOT NULL DEFAULT '',
