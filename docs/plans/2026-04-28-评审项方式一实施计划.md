# 实施计划：评审项方式一汇总表（合并单元格）

> 优化版本 v2 | 更新时间：2026-04-28 | 基于代码评审结果优化

## Context

当前系统的评审项在Word文档中以4张独立表格输出（complianceItems/technicalItems/creditItems/commercialItems），8列格式。用户需要新增**方式一**格式：一张5列汇总表，第一列按评审类别（资信标/技术标/商务标）垂直合并单元格，符合政府采购模板标准。

核心难点：poi-tl 的 `{{#list}}` 循环不支持单元格合并，需在渲染后用 Apache POI 的 CTVMerge 补做合并。

### 评审结论（v2 优化项）

| 评审项 | 结论 |
|--------|------|
| `XWPFTemplate.getXWPFDocument()` | **已验证可用**，返回 `NiceXWPFDocument extends XWPFDocument`，无需两阶段渲染回退 |
| 3个辅助方法缺失 | `setCellMerge()`/`clearCellText()`/`getCellText()` 补全实现 |
| 前端类型定义 | `review.ts` 预存在字段缺失，新增字段同时补齐 |
| PromptTemplates 语法 | 系统提示词用 `"""` 文本块+`{{`双写，用户提示词用 `%s`，不可混淆 |

```java
import java.math.BigDecimal;

private List<Map<String, String>> toReviewSummaryList(
        Map<String, List<TbProjectReviewItem>> grouped) {
    List<Map<String, String>> result = new ArrayList<>();

    List<String> orderedTypes = List.of("CREDIT", "TECHNICAL", "COMMERCIAL");
    Map<String, String> typeLabels = Map.of(
        "CREDIT", "资信标", "TECHNICAL", "技术标", "COMMERCIAL", "商务标");

    for (String reviewType : orderedTypes) {
        List<TbProjectReviewItem> items = grouped.getOrDefault(reviewType, Collections.emptyList());
        if (items.isEmpty()) continue;

        // 根节点总分
        BigDecimal categoryScore = items.stream()
            .filter(i -> i.getParentId() == null || i.getParentId() == 0)
            .map(TbProjectReviewItem::getMaxScore)
            .filter(Objects::nonNull)
            .reduce(BigDecimal.ZERO, BigDecimal::add);
        String categoryLabel = typeLabels.get(reviewType) + "（" + categoryScore.toPlainString() + "分）";

        // 父子关系映射
        Map<Long, List<TbProjectReviewItem>> childrenMap = items.stream()
            .filter(i -> i.getParentId() != null && i.getParentId() > 0)
            .collect(Collectors.groupingBy(TbProjectReviewItem::getParentId,
                LinkedHashMap::new, Collectors.toList()));

        List<TbProjectReviewItem> roots = items.stream()
            .filter(i -> i.getParentId() == null || i.getParentId() == 0)
            .sorted(Comparator.comparingInt(i -> i.getSortOrder() != null ? i.getSortOrder() : 0))
            .toList();

        for (TbProjectReviewItem root : roots) {
            flattenForSummary(root, categoryLabel, childrenMap, result);
        }
    }
    return result;
}

private void flattenForSummary(TbProjectReviewItem node, String categoryLabel,
        Map<Long, List<TbProjectReviewItem>> childrenMap,
        List<Map<String, String>> result) {
    boolean hasChildren = childrenMap.containsKey(node.getId())
        && !childrenMap.get(node.getId()).isEmpty();

    Map<String, String> map = new LinkedHashMap<>();
    map.put("categoryName", categoryLabel);
    map.put("reviewStandard", node.getItemName() != null ? node.getItemName() : "");
    map.put("maxScore", node.getMaxScore() != null ? node.getMaxScore().toPlainString() : "");
    map.put("subjectivity", hasChildren ? "" : formatSubjectivity(node.getSubjectivity()));
    map.put("responseFileCatalog",
        hasChildren ? "" : (node.getResponseFileCatalog() != null ? node.getResponseFileCatalog() : ""));
    result.add(map);

    if (hasChildren) {
        for (TbProjectReviewItem child : childrenMap.get(node.getId())) {
            flattenForSummary(child, categoryLabel, childrenMap, result);
        }
    }
}
```

**v2 优化**: 移除未使用的 `serialNo` 参数，简化 `flattenForSummary` 签名。

**列映射关系**:

| 模板列 | Map Key | 来源 |
|--------|---------|------|
| 评审分类（合并） | categoryName | reviewType→中文名 + 类别总分 |
| 评审标准 | reviewStandard | itemName |
| 最高分值 | maxScore | maxScore |
| 主观分/客观分属性 | subjectivity | subjectivity→客观/主观（复用 `formatSubjectivity()`） |
| 响应文件目录* | responseFileCatalog | responseFileCatalog（新字段） |

public byte[] render(InputStream templateStream, Map<String, Object> data,
                     List<MergeConfig> mergeConfigs) {
    Configure config = Configure.builder().build();
    try {
        byte[] cleaned = acceptAllRevisions(templateStream);
        try (ByteArrayOutputStream out = new ByteArrayOutputStream();
             InputStream cleanStream = new ByteArrayInputStream(cleaned)) {

**v3 补全**: 合并辅助方法 + 改进的 clearCellText，完整实现：

```java
private void applyCellMerges(XWPFDocument doc, List<MergeConfig> mergeConfigs) {
    List<XWPFTable> tables = doc.getTables();
    for (MergeConfig mc : mergeConfigs) {
        if (mc.getTableIndex() < 0 || mc.getTableIndex() >= tables.size()) continue;
        mergeColumnBySameText(tables.get(mc.getTableIndex()), mc.getColumnIndex());
    }
}

private void mergeColumnBySameText(XWPFTable table, int colIdx) {
    List<XWPFTableRow> rows = table.getRows();
    if (rows.size() <= 1) return;

    int startRow = 0;
    String currentText = getCellText(rows.get(0).getCell(colIdx));

    for (int i = 1; i <= rows.size(); i++) {
        String nextText = (i < rows.size()) ? getCellText(rows.get(i).getCell(colIdx)) : null;
        if (i == rows.size() || !currentText.equals(nextText)) {
            if (i - 1 > startRow) {
                setCellMerge(rows.get(startRow).getCell(colIdx), STMerge.RESTART);
                for (int j = startRow + 1; j < i; j++) {
                    setCellMerge(rows.get(j).getCell(colIdx), STMerge.CONTINUE);
                    clearCellText(rows.get(j).getCell(colIdx));
                }
            }
            startRow = i;
            currentText = nextText;
        }
    }
}

private void setCellMerge(XWPFTableCell cell, STMerge.Enum mergeType) {
    CTTcPr tcPr = cell.getCTTc().getTcPr();
    if (tcPr == null) tcPr = cell.getCTTc().addNewTcPr();
    CTVMerge vMerge = tcPr.isSetVMerge() ? tcPr.getVMerge() : tcPr.addNewVMerge();
    vMerge.setVal(mergeType);
}

/**
 * 清空单元格文本：保留第一个Run（维持格式），清空其文本；移除其余Run。
 * 避免保留空Run导致合并后单元格高度异常。
 */
private void clearCellText(XWPFTableCell cell) {
    for (XWPFParagraph para : cell.getParagraphs()) {
        List<XWPFRun> runs = para.getRuns();
        if (runs.isEmpty()) continue;
        runs.get(0).setText("", 0);
        for (int i = runs.size() - 1; i >= 1; i--) {
            para.removeRun(i);
        }
    }
}

private String getCellText(XWPFTableCell cell) {
    return cell.getText() != null ? cell.getText().trim() : "";
}
```

### 步骤7：WordDocumentServiceImpl - 集成合并配置

**文件**: `ele-ai-tender-file/.../service/impl/WordDocumentServiceImpl.java`

修改 `generateDocument()` 方法，当 data 包含 `allReviewItems` 时，自动构建 MergeConfig 并调用合并版 render：

```java
@Override
public Long generateDocument(Long templateFileId, Map<String, Object> data, String fileName) {
    String templatePath = fileStorageService.getFilePath(templateFileId);
    try (InputStream templateStream = new FileInputStream(templatePath)) {
        byte[] rendered;

        if (data.containsKey("allReviewItems")) {
            // 先清洗模板获取修订标记后的干净版本，确保表格索引与渲染时一致
            byte[] cleaned = templateEngine.cleanTemplate(templateStream);
            int tableIndex = findReviewTableIndex(new ByteArrayInputStream(cleaned));
            MergeConfig mc = new MergeConfig();
            mc.setTableIndex(tableIndex);
            mc.setColumnIndex(0);
            rendered = templateEngine.renderFromCleaned(cleaned, data, List.of(mc));
        } else {
            rendered = templateEngine.render(templateStream, data);
        }

        String bizType = "generated";
        FileUploadResponse response = fileStorageService.uploadFromBytes(
                new ByteArrayInputStream(rendered), fileName, bizType);
        return response.getFileId();
    } catch (Exception e) {
        throw new RuntimeException("基于模板生成文档失败: " + e.getMessage(), e);
    }
}

private int findReviewTableIndex(InputStream cleanStream) {
    try (XWPFDocument doc = new XWPFDocument(cleanStream)) {
        List<XWPFTable> tables = doc.getTables();
        for (int i = 0; i < tables.size(); i++) {
            for (XWPFTableRow row : tables.get(i).getRows()) {
                for (XWPFTableCell cell : row.getTableCells()) {
                    if (cell.getText() != null && cell.getText().contains("allReviewItems")) {
                        return i;
                    }
                }
            }
        }
    } catch (Exception e) {
        log.warn("无法定位评审汇总表索引", e);
    }
    return 0;
}
```

**v3 变更**: `findReviewTableIndex` 改为扫描**清洗后的模板**（与 poi-tl render 使用同一数据源），避免修订标记导致表格索引不一致。WordTemplateEngine 新增两个方法配合此改造：

```java
/** 清洗模板修订标记，返回清洗后的字节数组（供外部扫描表格索引） */
public byte[] cleanTemplate(InputStream templateStream) {
    try {
        return acceptAllRevisions(templateStream);
    } catch (Exception e) {
        log.error("模板清洗失败", e);
        throw new RuntimeException("模板清洗失败: " + e.getMessage(), e);
    }
}

/** 从已清洗的字节数组渲染模板（避免重复清洗） */
public byte[] renderFromCleaned(byte[] cleanedBytes, Map<String, Object> data,
                                List<MergeConfig> mergeConfigs) {
    Configure config = Configure.builder().build();
    try (ByteArrayOutputStream out = new ByteArrayOutputStream();
         InputStream cleanStream = new ByteArrayInputStream(cleanedBytes)) {
        XWPFTemplate template = XWPFTemplate.compile(cleanStream, config).render(data);

        if (mergeConfigs != null && !mergeConfigs.isEmpty()) {
            applyCellMerges(template.getXWPFDocument(), mergeConfigs);
        }

        template.writeAndClose(out);
        return out.toByteArray();
    } catch (Exception e) {
        log.error("Word模板填充失败", e);
        throw new RuntimeException("Word模板填充失败: " + e.getMessage(), e);
    }
}
```

### 步骤9：Word模板 - 设计5列表格

这是上传到文件服务的 `.docx` 模板文件（非代码），结构如下：

| 评审分类 | 评审标准 | 最高分值 | 主观分/客观分属性 | 响应文件目录* |
|---|---|---|---|---|
| {{?allReviewItems}}{{categoryName}} | {{reviewStandard}} | {{maxScore}} | {{subjectivity}} | {{responseFileCatalog}}{{/allReviewItems}} |

poi-tl 会为 allReviewItems 列表的每个元素复制此行。渲染后，WordTemplateEngine 自动合并第1列相邻同类单元格。

表格下方追加"注意"行和"*备注"行（静态内容，写在模板中）。
