## 目标

新建 `ele-tender-dev-tools` Maven 模块，实现统一 CLI 工具 `EleTenderDevCli`，覆盖招标文件和投标文件的生成与解密。

---

## 模块结构

```
ele-tender-system/
  ele-tender-dev-tools/
    pom.xml
    src/main/java/com/jy/eletender/devtools/cli/
      EleTenderDevCli.java           # main 入口 + 子命令分发
      TenderDocumentGenerator.java   # generate-tender
      TenderDocumentDecryptor.java   # decrypt-tender
      BidDocumentGenerator.java      # generate-bid
      BidDocumentDecryptor.java      # decrypt-bid
    src/test/java/com/jy/eletender/devtools/cli/
      EleTenderDevCliTest.java
      TenderDocumentGeneratorTest.java
      TenderDocumentDecryptorTest.java
      BidDocumentGeneratorTest.java
      BidDocumentDecryptorTest.java
```

## 实施步骤

### Step 1: Maven 模块
- 创建 `ele-tender-dev-tools/pom.xml`
- 依赖：`ele-tender-tender-document`、`ele-tender-crypto`
- 不含 Spring Boot plugin（非 Boot 应用）
- 配置 `exec-maven-plugin`
- 在父 POM `<modules>` 中注册

### Step 2: `EleTenderDevCli`
- `main()` → `run(args)` 模式（与 `FinalPackageCryptoCli` 一致）
- `args[0]` 分发到 4 个子命令

### Step 3: `TenderDocumentGenerator`
- 构造 `FinalPackagePayload` mock 数据
- 自动生成或接受 Base64 AES key
- 调用 `FinalPackageCryptoUtil.encrypt()`
- 输出 json / .HzctZbs / manifest，内置 round-trip 验证

### Step 4: `TenderDocumentDecryptor`
- 读取 .HzctZbs
- 调用 `FinalPackageCryptoUtil.decrypt()`
- 写出 JSON + 打印摘要

### Step 5: `BidDocumentGenerator`
- 构造 mock bid document + projectInfo
- password → SHA256 hex → 32 bytes key
- `JniCryptoNative`（自动 fallback Stub）
- `encryptSegments → rsaEncrypt → packFile`
- 输出 json / .HzctTbs / manifest，内置 round-trip 验证

### Step 6: `BidDocumentDecryptor`
- `unpackFile → decryptSegments → rsaDecrypt`
- 输出 bid document JSON + project info JSON

### Step 7: 测试
- 每个类 `@TempDir` 测试 round-trip
- CLI 分发测试（正确子命令、错误输入）
- `mvn -pl ele-tender-dev-tools -am test`：22 tests, 全通过

---

## 关键设计决策

| 决策 | 选择 | 原因 |
|------|------|------|
| 模块位置 | 新建 `ele-tender-dev-tools` | crypto 与 tender-document 互不依赖，避免交叉依赖 |
| CLI 参数解析 | 手写 `String[] args` | 与现有 CLI 风格一致，无新依赖 |
| native 检测 | try `System.loadLibrary` | `NativeLibraryLoader` package-private，直接重试加载 |
| Spring 上下文 | 不需要 | 所有工具类均 `new`-able |
| round-trip 验证 | 生成时内置 | 生成即验证，减少调试成本 |

## 验证命令

```bash
# 构建并测试
mvn -pl ele-tender-dev-tools -am test

# 运行生成招标文件
mvn -pl ele-tender-dev-tools exec:java \
  -Dexec.args="generate-tender -o ./dev-output"

# 运行生成投标文件
mvn -pl ele-tender-dev-tools exec:java \
  -Dexec.args="generate-bid -o ./dev-output"

# 运行解密招标文件（key 从 tender-manifest.json 获取）
mvn -pl ele-tender-dev-tools exec:java \
  -Dexec.args="decrypt-tender -i ./dev-output/sample-tender-document.HzctZbs -k <base64Key>"

# 运行解密投标文件
mvn -pl ele-tender-dev-tools exec:java \
  -Dexec.args="decrypt-bid -i ./dev-output/sample.HzctTbs -p BidderPwd@2026!"
```
