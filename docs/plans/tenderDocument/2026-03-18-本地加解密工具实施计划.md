# 本地加解密工具实施计划

## 实施项

1. 新增 `FinalPackageCryptoUtil`，沉淀统一 AES-GCM 加解密实现。
2. 新增 `FinalPackageCryptoCli`，支持对本地文件执行加密/解密。
3. 让 `DefaultFinalPackageEncryptor` 复用 `FinalPackageCryptoUtil`，确保生产/测试同源。
4. 新增单元测试：
   - `FinalPackageCryptoUtilTest`
   - `FinalPackageCryptoCliTest`

## 验证命令

- `mvn -Dtest=FinalPackageCryptoUtilTest,FinalPackageCryptoCliTest,DefaultFinalPackageEncryptorTest test`
- `mvn -pl ele-tender-tender-document -am test`
