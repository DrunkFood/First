# 2026-03-18 最终文件回传联调收尾实施计划

## 实施步骤
1. **补测试（RED）**
   - 在 demo 模块新增/更新测试，断言回调 SPI 在收到 `fileId` 后会调用 `EleTenderInteractionClient` 的查询与下载能力。
   - 断言回调记录包含下载结果字段。

2. **最小实现（GREEN）**
   - 扩展 `DemoCallbackRecord`：增加下载状态、下载大小、错误信息等字段。
   - 改造 `DemoInteractionTenderPdfReceiveService`、`DemoInteractionTenderPackageReceiveService`：在留痕前执行 `getFileInfo + downloadFile`，捕获异常并落库错误信息。

3. **验证与收尾**
   - 运行 demo 模块相关测试。
   - 输出变更摘要、影响点和联调使用说明。

## 风险与控制
- 风险：联调环境下文件服务不可达导致回调链路抛错。
- 控制：SPI 内部吞掉文件拉取异常并记录，不影响回调接口本身响应。
