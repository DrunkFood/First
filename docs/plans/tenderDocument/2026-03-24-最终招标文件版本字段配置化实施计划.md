# 2026-03-24 最终招标文件版本字段配置化实施计划

## 目标
将最终数据包 `versionInfo` 中的 `tenderDocumentAppVersion` 与 `tenderDocumentFormatVersion` 从硬编码改为配置驱动。

## 实施步骤
1. 新增配置承载类（`@ConfigurationProperties`），定义：
   - `tender-document.version.app-version`（整数）
   - `tender-document.version.format-version`（字符串）
2. 在 Spring 配置中注册该配置类。
3. 调整 `TenderDocumentGenerationServiceImpl` 注入并使用新配置值填充 `versionInfo`。
4. 更新 `application.yml` 与本地示例配置，补充默认值与注释。
5. 先写失败测试（TDD）：校验生成时 `versionInfo` 使用配置值。
6. 实现后运行最小相关测试并修正。

## 风险与控制
- 风险：配置缺失导致启动失败或生成异常。
- 控制：提供默认值；字段类型与注释语义保持一致（app-version 为整数）。

## 回滚方案
- 回退本次配置类与注入改动，恢复硬编码逻辑。
