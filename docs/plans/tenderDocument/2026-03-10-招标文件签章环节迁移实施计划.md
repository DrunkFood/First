# 招标文件签章环节迁移 Implementation Plan

> 备注：本文件为签章迁移的实施计划留档。对应改动已落地到当前代码与文档，后续查阅现行约定时，以 `ele-tender-system/ele-tender-tender-document/README.md`、`docs/projects/2026-03-04-招标文件编制系统接口文档-openapi3.yaml`、数据库脚本与模块代码为准。

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 去掉招标文件编制系统中的独立签章步骤，并把签章文件绑定能力迁移到采购文件上传环节，同时保持生成与回传链路可用。

**Architecture:** 保留 `SIGNED_PDF` 文件角色与生成/回传职责，只调整步骤流与文件页聚合方式。后端以“采购文件页同时管理源采购文件和签章文件”为中心改造，优先收敛步骤状态机，再兼容接口、文档和测试。

**Tech Stack:** Java 21, Spring Boot 3.2.2, MyBatis-Plus 3.5.5, JUnit 5, Mockito, OpenAPI YAML, Markdown 文档
