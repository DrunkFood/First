> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 完成 `tender-document` 与业务系统的正式交互闭环，并新增一个独立 Git 的 demo 业务系统作为 starter 接入样例。

**Architecture:** 主仓库负责正式交互 Gateway、日志、错误处理和文档；`demo-business-system/` 作为嵌套独立 Git 仓库，使用内存样例数据实现 5 个 SPI，并提供业务侧主动调用电子标的示例接口。

**Tech Stack:** Java 21、Spring Boot 3.2.2、Maven、Spring MVC、JUnit 5、MockMvc、ConcurrentHashMap
