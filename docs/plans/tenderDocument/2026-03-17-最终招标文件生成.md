# 最终招标文件生成 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将招标文件编制系统的生成页从临时数据包生成改造成正式的最终招标文件数据包生成、保存、下载与回传能力。

**Architecture:** 保持单个 `/generate` 同步入口，对内拆分为状态抢占、最新数据组装、签章 PDF 加载、最终 JSON 构建、加密、文件服务保存、`采购文件编制信息` 生成与业务留痕几个独立职责。生成与回传解耦，生成成功后编制单进入 `COMPLETED`，回传只消费已保存的文件。

**Tech Stack:** Java 21, Spring Boot 3.2.2, MyBatis-Plus 3.5.5, Jackson, JUnit 5, Mockito, Markdown, OpenAPI YAML
