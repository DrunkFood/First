# 招标/投标文件后缀可配置化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让每个接入系统（appKey）可以独立配置招标文件后缀（默认 `.HzctZbs`）和投标文件后缀（默认 `.HzctTbs`），存储在 `sup_access_system` 表中，通过支撑中心管理界面维护。

**Architecture:** 在 `SysAccessSystem` 实体上新增 `tenderDocumentSuffix` 和 `bidDocumentSuffix` 两个字段。tender-document 和 crypto 模块通过已有的 `selectByAppKey` Mapper 查询后缀。在 `ele-tender-common` 中定义 `FileConstants` 提供默认值。Gateway 接口增加 `suffix` 参数。前端在接入系统编辑表单中增加两个输入框。

**Tech Stack:** Java 17 / Spring Boot / MyBatis-Plus / Vue 3 + Element Plus + TypeScript

- [ ] **Step 1: 验证 CRUD 行为**

MyBatis-Plus 的 `BaseMapper.insert()` / `selectById()` / `selectPage()` 会自动包含新字段，无需额外改动。
