# 外部 Token 与签名时效开关实施计划

**Goal:** 将外部 token 有效期与签名有效期改为可配置，并保证默认值满足当前联调需求。

**Scope:** `ele-tender-common`、`ele-tender-support`。

### Task 1: 测试先行（RED）
- 为 `JwtUtil` 增加“自定义外部 token 过期时长”测试。
- 为 `SignatureUtil` 增加“自定义签名时间窗”测试。
- 为 `AuthServiceImpl` 增加“配置化签名时间窗生效”测试。

### Task 2: 实现配置化能力（GREEN）
- `JwtUtil` 增加外部 token 自定义过期时长重载方法。
- `SignatureUtil` 增加签名校验自定义时间窗重载方法。
- `AuthServiceImpl` 接入 `jwt.external-expiration` 与 `signature.expire-seconds`。
- `application.yml` 默认值更新为联调期配置（外部 token 7 天）。

### Task 3: 验证
- 运行 `ele-tender-common` 与 `ele-tender-support` 最小相关测试，确认新增与存量测试通过。
