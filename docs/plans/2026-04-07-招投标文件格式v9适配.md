# 招投标文件格式 v9 适配实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将招投标文件中的 `bidForms` 从固定字段结构适配为 v9 的 `schemeContent`（标录方案）+ `bidFormData`（标录数据）动态结构，并清理无用字段。

**Architecture:** 清理 `BidRecordSchemeResponse` 中的 3 个无用字段（schemeId/schemeName/schemeVersion），使其只保留 `schemeContent`。更新 dev-tools mock 生成器以产出 v9 格式。修复所有受影响的测试。

**Tech Stack:** Java 21 · Spring Boot 3.2.2 · MyBatis-Plus · Maven · JUnit 5 + Mockito + AssertJ
